# Lightstack Documentation

Lightstack is a lightweight, single-binary reimplementation of the core OpenStack
control plane — Keystone identity, Nova compute (full server lifecycle), Neutron
networking (including VXLAN multi-node), Cinder volumes, and Glance images — with an
EC2 metadata service, noVNC console access, and OpenStack API compatibility
verifiable with real OpenStack clients.
